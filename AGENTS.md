# Instructions for coding agents

Read `README.md` and `CONTRIBUTING.md` before editing this repository.

- Complete one coherent change, run relevant checks, commit with a Conventional Commit message, and push before starting the next change. This cadence is explicitly requested by the repository owner.
- Inspect the working tree first. Preserve unrelated work and stage only your own files.
- Do not force-push or rewrite shared history. If pushing is blocked, report the issue clearly.
- Keep implementation scope aligned with the self-healing automation challenge and the README's planned/implemented distinction.
- Preserve the recovery-system invariants in `CONTRIBUTING.md`.
- Never commit secrets, real student data, local databases, or generated telemetry.
- Do not claim an external ERP integration, a successful repair, or a passing check without evidence.
